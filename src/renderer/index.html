First-time setup
  1. In OBS, open Tools → WebSocket Server Settings and enable the server. Use Show Connect Info for its address and password.
  2. In Clone Hero, enable Export Current Song. Select the folder where the game writes currentsong.txt.
  3. Save your connection and scene preset, then select Start switching if the switcher is paused.
